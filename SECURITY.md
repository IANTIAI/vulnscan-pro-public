# Security policy

## Supported versions

Only the latest release (1.5.x) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's **Report a vulnerability** button (Security tab → private vulnerability reporting) and share a minimal reproduction without real IP addresses, host names, credentials or customer data.

## Safe operation

Use VulnScan only on systems and networks you are authorized to assess. Active Nmap checks can generate traffic, trigger alerts, or affect fragile/industrial devices.
